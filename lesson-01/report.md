# Greeting Program Comparison Report

The AI version was faster and more polished in wording, so it felt more natural for a user-facing greeting. The manual version was more explicit about validation and edge cases, which made it easier to understand the logic and the error handling. The AI-generated code was concise and readable, but it was slightly less careful about the empty-input case unless prompted. Overall, the AI did better at speed and style, while the human version did better at deliberate correctness and practical robustness.
